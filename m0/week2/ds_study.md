---

## 0. 一句话总纲

深度学习「训练」从头到尾只干一件事，反复循环：

```
前向算预测 → 算误差(loss) → 反向求梯度 → 用梯度更新参数
```

下面每节展开一个词，最后你会看到它们怎么拼成这条线。

---

## 1. 模型在干什么：从「参数」到「预测」

模型本质上是一个**带旋钮的公式**。最简单的例子：

```
y = w·x + b
```

- `x` 是输入（你喂进去的数据）
- `w`、`b` 是**参数**，就是「旋钮」，一开始是随机数
- `y` 是输出（预测结果）

「前向传播」(forward) 就是把 x 代入公式、顺着算一遍，得到 y。

**参数是模型里唯一需要「学」的东西**——训练的全部目的，就是把这些旋钮拧到合适的位置。

---

## 2. 损失函数（loss）：衡量「错得有多离谱」

模型预测出 y，但真实答案可能是 y_true。损失函数就是量一下两者差多远：

```
loss = (y - y_true)²     # 这只是其中一种（均方误差）
```

关键性质：**loss 是一个标量，也就是一个数**。loss 越大 = 错得越离谱；loss 越小 = 预测越准。

所以训练目标一句话：**把 loss 弄到尽量小。**

---

## 3. 梯度：loss 对每个参数的「敏感度」

现在的问题是：**我该往哪个方向拧旋钮，才能让 loss 变小？**

先回到高中的导数。单变量时：

```
dy/dx = 2x + 3
```

意思是「x 变一点点，y 会变多少」。你代码里的 T1 就是这个：

```python
x = torch.tensor([2.0], requires_grad=True)
y = x ** 2 + 3 * x + 1
y.backward()
print(x.grad)   # 7.0
```

`dy/dx = 2x + 3`，代入 x=2 → `7`。这就是「x 对 y 的敏感度」。

多变量时，这个概念推广为**偏导**：

```
∂loss/∂w  表示「只动 w 这个旋钮，其他不动，loss 会怎么变」
∂loss/∂b  表示「只动 b 这个旋钮，loss 会怎么变」
```

把所有这些偏导打包成一个向量，就叫**梯度**（gradient）：

```
梯度 = [∂loss/∂w, ∂loss/∂b, ...]
```

**梯度指向「loss 上升最快」的方向。** 所以想减小 loss，就往梯度的**反方向**走一步。这就是训练的核心思想。

---

## 4. 计算图：把计算过程画成一张依赖图

一个复杂模型的前向计算，可以拆成很多小步骤，每一步是「输入 → 运算 → 输出」。
把这些步骤按依赖关系连起来，就是**计算图**。

你 T1 的 `y = x² + 3x + 1`，拆开就是：

```
        x
       / \
    x²     3x        ← 中间结果
       \ /
        +            ← y = x² + 3x + 1
        |
        y
```

- **节点** = 张量或运算
- **边** = 数据流向
- **前向传播** = 顺着图从左走到右，算出最终结果

PyTorch 在你做运算时**自动、悄悄地把这张图画好**（前提是输入标了 `requires_grad=True`）。
所以 `b = a * 10` 这种代码，表面只是算个数，背后 PyTorch 已经记下了「b 依赖 a，运算是乘法」。

---

## 5. 链式法则：把「对输出的导数」转成「对每个参数的导数」

单看一节图，我们能算的是「输出对这个节点输入的导数」。但我们要的是「loss 对每个参数的导数」。
中间隔着好多层，怎么连起来？靠**链式法则**：

```
∂loss/∂x = (∂loss/∂y) · (∂y/∂x)
```

也就是「对输出的导数 × 输出对输入的导数」。一层一层乘下去：

```
loss → ... → y → x → w
```

```
∂loss/∂w = (∂loss/∂y) · (∂y/∂x) · (∂x/∂w)
```

一句话：**把沿途每一小段的导数乘起来。**

---

## 6. 反向传播：从 loss 出发，反着走一遍

有了链式法则，就能做「反向传播」(backpropagation)：

- **前向**：从左到右，把每个节点的值算出来（正向走图）
- **反向**：从 loss 出发，从右到左，用链式法则把「对每个节点的梯度」逐个算出来

因为 loss 是标量，从它开始反着走，每个参数最终都能得到一个「∂loss/∂参数」的标量值。

这就是你调用的 `y.backward()` 在做的事：**沿着计算图反向走一遍，把每个 `requires_grad=True` 的叶子张量的 `.grad` 填上。**

---

## 7. PyTorch 的 autograd：这套东西怎么落地

PyTorch 把这套机制做成了自动的（叫 autograd），你只需要懂三个东西：

| 概念 | 作用 |
|---|---|
| `requires_grad=True` | 声明「这个张量要参与求导」，PyTorch 开始为它建图 |
| `tensor.backward()` | 触发反向传播，计算梯度 |
| `tensor.grad` | 反向传播算完的结果，存的就是 `∂loss/∂这个张量` |

所以你代码里：

```python
w = torch.tensor([1.0, 2.0], requires_grad=True)  # 声明要追踪
y = w * w                                           # 前向，自动建图
y.backward(gradient=torch.ones_like(y))             # 反向，算梯度
print(w.grad)                                       # [2.0, 4.0]
```

`w.grad = [2, 4]` 的含义：如果把 loss 看成 `sum(y)`（因为传了全 1 的 gradient），那么
「w[0] 增大一点，loss 增大 2」「w[1] 增大一点，loss 增大 4」。

---

## 8. 参数更新：梯度算出来之后干嘛

梯度告诉你「往哪走 loss 会变大」，那就往**反方向**走：

```
w_new = w_old - lr * ∂loss/∂w
```

- `lr` 是**学习率**(learning rate)，控制每次走多大步
- 走完一步，loss 通常就小一点
- 反复走，loss 越来越小 → 模型越学越准

---

## 9. 串起来：一个完整的训练循环

把上面所有概念拼起来，就是你以后会天天写的训练代码：

```python
for 每批数据:
    pred = model(x)            # ① 前向传播，自动建图
    loss = 损失函数(pred, 真实) # ② 算误差，得到一个标量

    optimizer.zero_grad()      # ③ 清零上一步的梯度（对应你 T2 的考点）
    loss.backward()            # ④ 反向传播，算出所有参数梯度
    optimizer.step()           # ⑤ 用梯度更新参数
```

这就是「训练」的完整闭环，每一步都对应前面讲的一个概念。

## 11. 几个易混点澄清（对应思考题）

- **`gradient` 参数**：不是「让 grad 变成向量」，而是补上链式法则里缺的 `∂L/∂y` 这一项。
  y 是标量时它默认是 1，所以不用传；y 是向量时 PyTorch 不知道你怎么把 y 合成标量，必须传。

- **`w.grad` 的形状**：永远和 `w` 一样。它存的是「某个标量 loss 对 w 的导数」，不是「y 对 w 的导数」（后者是矩阵）。

- **梯度累加**：`backward()` 算出的梯度是**加到** `w.grad` 上的，不是覆盖。所以每轮训练前要 `zero_grad()`，否则会带着上一步的旧梯度一起更新，结果就错了。

- **`requires_grad` 是「是否追踪」不是「是否有数值」**：`detach()` 出来的张量数值不变，只是脱离了计算图，不能再反传。

---

## 12. 一句话记住整条链

> 前向传播顺着计算图算出 loss（一个数）→ 反向传播用链式法则反着走，算出 loss 对每个参数的梯度 →
> 沿梯度反方向更新参数 → loss 变小 → 重复。PyTorch 的 autograd 帮你自动做了「建图」和「反着走」这两件事。
